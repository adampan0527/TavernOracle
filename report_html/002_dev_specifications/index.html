1. 技术栈选型与语言职责划分

为满足 30 秒绳子时间内输出极低时延决策，并最大化复用炉石开源生态，工程划分为三大语言阵营：

主干首选 · C# (.NET 8)

生产级 HDT 插件宿主

深度整合国际开源基础设施：HearthDb（全卡牌元数据）、Bob's Buddy（千次蒙特卡洛战力模拟）及 LogWatcher。

  • 1~2 周即可快速交付可用 MVP
  • 原生 WPF 穿透悬浮窗与 Win32 吸附
  • 算法求解耗时 $\le 5\text{ ms}$
备选轻量 · Rust + Tauri

跨平台独立客户端

脱离 HDT 宿主独立运行，Rust 负责异步读取 Power.log，前端由 Webview2 渲染现代毛玻璃 HUD。

  • 内存占用极低（< 40MB）
  • 现代前端（TypeScript / Tailwind）丰富动效
  • 强类型内存安全，零 GC 垃圾收集干扰
研究与离线 · Python (PyTorch)

AI 行为克隆与模型训练

负责解析万分段职业选手实战录像（Replay），训练 Set Transformer 跨实体自注意力模型。

  • 导出为 ONNX 格式交付运行时推理
  • 零样本机制语义向量编码（Zero-Shot）
  • 天梯胜率矩阵与单卡先验爬虫管道

2. 15ms 零 GC 编码与合规红线

⚡ 零 GC 垃圾回收优化

在 30 秒密集决策阶段，避免垃圾回收导致的掉帧卡顿：

  • 严禁在 DP 搜索循环中调用 new 分配短期堆对象。
  • 禁止高频使用 LINQ，改用定长数组与内存池 ArrayPool<T>。
  • 种族与状态采用整型位掩码（BitMask），协同计算复杂度达到 $O(1)$。

🛡️ 绝对安全红线清单

严格遵守暴雪“纸笔准则（Pencil & Paper Rule）”：

  • 严禁调用 mouse_event、SendInput 进行任何键鼠模拟。
  • 严禁 DLL 注入或 ReadProcessMemory 内存扫描。
  • 所有游戏事件只能通过本地官方调试日志 Power.log 读取。
